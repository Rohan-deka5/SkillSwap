# SkillSwap

SkillSwap is a web application designed to facilitate peer-to-peer skill exchange. The platform empowers users to connect with others to teach what they know and learn what they need, all within a clean, distraction-free environment.
Features

    Dashboard: A welcoming home page with the project's mission statement and a quick link to browse skills.

    Peer Forum: A directory of users, showcasing the skills they offer and the skills they are looking to learn.

    My Sessions: An organized view of upcoming and past skill-exchange sessions, with the ability to schedule new ones.

    Profile Management: A dedicated page to manage and update the skills you are offering and the skills you want to learn.

    Video Call Interface: A simple, functional interface for one-on-one video calls to conduct sessions.

    Search Functionality: A modal search feature to quickly find users based on the skills they offer.

    Theme Toggle: A one-click button to switch between light and dark modes for a personalized viewing experience.

    Subscription Plans: A page detailing different subscription tiers with distinct visual themes.
